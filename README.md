# Lo que debes saber sobre este repositorio:
## Quiero contribuir, ¿cómo puedo hacerlo?
Para colaborar en este repositorio debes hacer una pull request que contenga únicamente archivos de Hello World en lenguajes que no haya aún en este repositorio.

En caso de querer corregir o reducir el número de líneas, hazlo con un issue.
## Normas para contribuir:
1. El programa o script solo debe imprimir.
2. Solo debe imprimir "Hello World", "Hello, World", "Hello, World!" o "Hello World!".
3. Solo se puede imprimir texto en inglés.
